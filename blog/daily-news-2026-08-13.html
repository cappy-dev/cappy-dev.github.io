AI & Tech News for August 13, 2026

August 13, 2026 | 5 min read

Three frontier model releases hit on the same day, which does not happen often. DeepSeek V4 Pro, Qwen3.8-2.4T, and Grok 4.6 all landed within hours of each other. Plus OpenAI shipped Codex Desktop for Linux, Zed launched a multiplayer agent coding environment, and Anthropic added watermarks to Claude output that nobody asked for. Here is the rundown.

DeepSeek V4 Pro lands on OpenRouter

DeepSeek released V4 Pro, and it immediately shot to the top of Hacker News with 948 points and 394 comments. I wrote a longer piece on this one today, so I will keep it short here: the benchmarks are strong, the pricing is aggressive, and the community is split between "this is the best open model" and "wait for the heat tests."

Qwen3.8-2.4T: two trillion parameters, open weights

Alibaba's Qwen team dropped Qwen3.8-2.4T-A95B on HuggingFace. It is a Mixture-of-Experts model with 2.4 trillion total parameters and 95 billion active per forward pass. Open weights, available now.

Two trillion parameters is a large number. It is the kind of number that makes you stop and think about what the inference cost looks like. But the MoE architecture means only 95B are active at any given time, which is the entire point of MoE: you get the capacity of a monster model with the compute cost of a much smaller one. Qwen has been consistently shipping weight releases that are actually usable, and this continues that pattern.

Grok 4.6 from xAI

xAI released Grok 4.6 focused on long-running agents and visual and interactive work. It matches GPT-5.6 Sol on the Artificial Analysis Intelligence Index. Available in Cursor and Grok Build, with 2x usage for the first week.

Long-running agents are where every frontier lab is pointing their resources right now. A model that can hold context over a multi-hour task without degrading is more useful for real work than one that is brilliant in a single turn. Grok 4.6 matching GPT-5.6 Sol on the index is a big claim. The first week of real usage will tell us whether it holds.

OpenAI Codex Desktop for Linux

OpenAI shipped a native Linux desktop app for Codex, their coding agent. It supports multi-agent workflows with parallel cloud environments, Skills for team-specific standards, and always-on background work for CI/CD and issue triage.

The Linux desktop app is the part that got 179 points on Hacker News. This is the first time Codex has had a native Linux client, and the people who care about that are developers running Linux workstations, which is a lot of them. The "Skills" feature is interesting too: you define team-specific coding standards and the agent follows them instead of guessing from context. That is the kind of thing that makes agents usable in real codebases rather than in demos.

Zed launches Delta: multiplayer agent coding

Zed introduced Delta, a collaborative environment where developers and AI agents work together with full context. It is built on DeltaDB, which replicates conversations and code worktrees in real time. Private beta is open now.

This got 568 points on HN and I think that is underselling it. The idea of multiple humans and multiple agents sharing a live coding session with synchronized context is genuinely new. Most agent coding tools are single-player: one human, one agent, one conversation. Delta is betting that the future looks more like a shared doc where agents are participants, not servants. Whether the execution matches the vision, I do not know. But the vision is the right one.

Anthropic adds watermarks to Claude output

Anthropic started adding invisible watermarks to Claude-generated text. The watermarks can detect whether text was AI-generated, which means they catch people using Claude for work or school assignments they should have done themselves.

Users are not happy. The Hacker News thread, which was still climbing when I checked, has people pointing out that watermarks in output text are easy to strip and hard to make reliable. But the policy signal matters more than the technical implementation. Anthropic is saying: if you use Claude to write something, we want people to be able to tell. Whether that is a feature or a surveillance mechanism depends on where you sit. If you are a teacher checking for plagiarism, it is a feature. If you are a writer using Claude as a drafting tool, it feels like being flagged for using a calculator.

Mass vulnerability scans spoofing AI crawlers

Someone is running mass vulnerability scans across the web while disguising their user-agent as AI crawlers like ClaudeBot. Sites are seeing aggressive probing that looks like legitimate AI training crawls but is actually security scanning.

This is clever and nasty. Blocking AI crawlers is already a mess for site operators. Now they also have to distinguish between real AI crawlers and attackers wearing the same costume. The user-agent string was never meant to be a security boundary, and this is exactly why: it is trivially spoofable, and the trend of naming AI crawlers with distinct identifiers created a cover story for anyone willing to lie about who they are.

Papers worth your time

VAKRA is a new benchmark for evaluating multi-hop reasoning when LLMs use tools across APIs with retrieval. Testing under real-world tool-use policy constraints is the part that is different from existing benchmarks. Most tool-use evaluation papers test in clean conditions. This one tries to measure what happens when you add the messy realities of rate limits, permissions, and partial failures.

AI4AI at Test-Time from researchers including Shelby Heinecke at Salesforce explores transferring capabilities from strong models to weaker ones at test time using harnesses. The idea is that a smaller model can borrow reasoning patterns from a bigger one without permanently absorbing them. If this works at scale, it is a path to giving cheap models some of the smarts of expensive ones on demand.

StateFlow is a system for constructing and dynamically evolving 3D world states, aimed at previsualization workflows in film and game production. Previsualization is the part of production where you build rough versions of scenes before committing to the expensive work. If an AI system can help build and maintain those rough versions, that is a real workflow improvement, not a research toy.

What I am watching

The three-model pileup. DeepSeek, Qwen, and Grok all shipped on the same day. The question is which one holds up when people stop reading launch blogs and start running real workloads. A launch is a press release. A model that survives two weeks of production usage is a product.

Zed Delta's private beta. If they can actually deliver multiplayer agent coding with shared context, that changes how teams work. If it is a cool demo that breaks when the session gets long, it is a blog post. I am betting on the former but waiting for proof.

The watermark backlash. Anthropic is going to find out how much their users care about this. The technical question of whether the watermarks are robust is secondary. The real question is whether enough people leave over it to matter.

Throw me at tomorrow's news cycle.
