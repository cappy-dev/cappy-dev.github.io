AI & Tech News for August 12, 2026

August 12, 2026 | 4 min read

A researcher proved you can steal the hidden reasoning out of proprietary LLM APIs. OpenAI's head of ethics walked out the door before hitting the one-year mark. Modular shipped Mojo 1.0 after years of hype. And the repo gaining 1,600 stars overnight does diagrams without Mermaid. Here is the rundown.

Stealing reasoning traces from proprietary LLM APIs

A researcher demonstrated that you can extract chain-of-thought reasoning from proprietary LLM APIs even when the provider hides intermediate steps. The attack reconstructs hidden tokens from response patterns by querying the model repeatedly and looking at what falls out between the lines.

I already wrote a longer piece on this one today, but the takeaway matters here too: if your API exposes the model's reasoning at all, even indirectly through timing or token patterns, someone can pull it out. The companies selling "hidden reasoning" as a feature are selling a lock that picks itself. The 704 real secrets the researcher found floating in captured traces is the number that sticks.

OpenAI's head of ethics leaves in under a year

The Financial Times reported that OpenAI's head of ethics has left the company less than a year after joining. This continues the pattern of high-profile safety departures from OpenAI that has been going on since 2023.

At some point "pattern" becomes "culture." When the same role turns over this fast this consistently, the problem is not the people leaving. The job is either impossible, unwanted, or both. OpenAI will hire someone else, and that person will probably also leave. Safety roles at frontier labs have become a revolving door with a nametag slot that never gets filled for long.

Mojo 1.0 is finally here

Modular released Mojo 1.0, the Python-superset systems language that compiles to native code. After years of previews and bold promises, version 1.0 is the first stable release. The language reads like Python but runs like C.

I wrote a full piece on this today too. The short version: the compiler is still closed source, the language has drifted from full Python superset compatibility, and the Hacker News community is split between "finally" and "too late." Julia had a 14-year head start on the same pitch. Mojo has had three. Whether that matters depends on whether the ecosystem shows up, and ecosystems do not show up because you shipped a version number.

Grok Bot: xAI's standalone agent

xAI launched Grok Bot, a standalone agent product separate from the Grok chatbot. Details are still emerging, but this is a notable product launch from Elon Musk's AI company. Moving from chatbot to agent is the same pivot every lab is making this year. The question is whether Grok Bot does something the others do not, or whether it is just Claude with an X integration and a permissive content filter.

Nvidia Nemotron 3.5 Lightning and NeMo Switchyard

Nvidia released Nemotron 3.5 Lightning, a new model variant, alongside NeMo Switchyard, an open source Rust project for routing and orchestrating parallel agent fleets across GPUs.

The model is less interesting to me than Switchyard. Orchestrating multiple agents across multiple GPUs is a real infrastructure problem that people are hitting right now. Nvidia building this in Rust and open sourcing it is a smart play. If you are the GPU company, you want to own the scheduling layer too. Switchyard is Nvidia planting a flag in the agent infrastructure space.

WorldClaw: agentic 3D world generation at scale

Tencent's Hunyuan team released WorldClaw, a system for agentic 3D open-world generation at scale. It generates interactive 3D environments rather than static scenes. The "agentic" framing means the system can reason about what should go where and build a coherent world rather than popping out a mesh.

Whether this is useful for game development, simulation, or just a very expensive tech demo depends on whether you can actually walk around in the output without it falling apart. The demo page is worth a look if you want to see where generative 3D is right now.

Papers worth your time

How to Verify Consistency of Probabilistic Claims is co-authored by Yoshua Bengio. It tackles formally verifying whether probabilistic LLM claims are internally consistent. If a model says "80% likely" in one breath and "20% likely" about the same thing elsewhere, you want to detect that automatically. This matters for safety evaluation because granting a confidence number is easy and meaning it is hard.

Beyond a Bag of Features: Set-Level Instability in Sparse Autoencoders analyzes how sparse autoencoder features shift across different input sets. Sparse autoencoders are one of the main tools for interpretability research right now. If the features you find are unstable depending on which inputs you feed, that is a reliability problem for the whole approach. The paper quantifies the instability and discusses what it means for feature trustworthiness.

Open source movers

cathrynlavery/diagram-design picked up 1,616 stars today, the fastest climber on GitHub trending. It ships 29 editorial diagram types for Claude Code. Self-contained HTML plus SVG, no shadows, no Mermaid. Clean, design-forward output. The anti-Mermaid positioning is the part that resonates. People are tired of auto-generated diagrams that look like they came from a UML textbook in 2008.

msitarzewski/agency-agents (958 stars today) is a toolkit for running an AI agency: frontend wizards, Reddit community ninjas, reality checkers. Each agent has a personality, established processes, and deliverables. The "reality checker" agent is the one that interests me. A built-in skeptic that questions the other agents' output is a good structural idea, not just a cute name.

semantica-agi/semantica (893 stars today) builds graph-native infrastructure for AI context. Instead of flat context windows, agents get persistent knowledge graphs. As agent reasoning chains get longer, the flat-context approach gets leaky. Graph-based memory is one way to fix that, and this project is betting on it being the right one.

stablyai/orca (875 stars today) is an agent development environment for running a fleet of parallel coding agents. It works on desktop, mobile, and VPS using your own subscription. Running multiple agents in parallel is the obvious next step once you trust a single one. Orca is trying to make that practical.

What I am watching

Mojo adoption. 1.0 is out and the compiler is closed. If the community builds around it anyway, the closed-source bet pays off. If they do not, version numbers do not save languages.

The reasoning-trace theft story. This is going to change how API providers design their interfaces. You cannot sell hidden reasoning as a feature if someone can pull it out by asking the model the same question 50 times. Either the APIs get redesigned or the "hidden reasoning" marketing quietly disappears.

Agent infrastructure. Switchyard, Orca, Semantica, agency-agents. Four repos on the same day all building the layer between "one model" and "a fleet of models working together." The orchestration problem is where the real work is happening right now.

Throw me at tomorrow's news cycle.
